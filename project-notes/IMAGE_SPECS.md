# Размеры картинок для сайта «Чайный путь»

Подготовь изображения в этих размерах и с такими названиями. Если пришлешь мне файлы, я заменю их в `public/assets`.

| Где используется | Размер | Имя файла | Что должно быть на картинке |
| --- | --- | --- | --- |
| Главный hero-баннер | 1280x380 px | `hero-tea.jpg` | Широкий чайный кадр. Главный объект справа или по центру, без текста на самой картинке. |
| Hero раздела «Подарки» | 1280x360 px | `gift.jpg` | Подарочный набор, упаковка, чайный комплект. |
| Hero «Акции» | 1280x360 px | `promotions.jpg` | Акционная подборка или красивый набор товаров. |
| Hero «О магазине» | 1280x360 px | `tea-set.jpg` | Чайный стол, посуда, аккуратная композиция. |
| Hero «Подбор чая» | 1280x360 px | `pick-tea.jpg` | Чай, рука, посуда или процесс выбора чая. |
| Карусель на главной | 760x360 px | `shen-puer-lesnoy.jpg`, `gift.jpg`, `tea-set.jpg` | Горизонтальные кадры, главный объект в центре. |
| Карточки товаров | 800x800 px | файлы товаров | Квадрат. Товар целиком внутри кадра, с небольшими полями по краям. |
| Карточки подарков | 800x800 px | `tea-set.jpg`, `gift.jpg` | Набор целиком, не обрезать коробку или посуду. |
| Акции недели | 720x520 px | `oolong.jpg`, `gift.jpg`, `tea-set.jpg` | Горизонтальная промо-картинка, объект в центре. |
| Сценарии на главной | 620x360 px | `hero-tea.jpg`, `gift.jpg`, `tea-set.jpg` | Широкий фон без мелкого текста. |
| Блок «Собственное производство» | 760x520 px | `tea-set.jpg` | Мастерская, набор, упаковка или чайный стол. |
| Страница товара | 900x820 px | файл конкретного товара | Почти квадрат, товар полностью помещается в кадр. |
| Логотип | 512x512 px | `logo.png` | Круглый или квадратный логотип без лишних полей. |

Важно:
- Не вставляй текст прямо в картинку, текст уже есть на сайте.
- Для карточек лучше делать квадрат `800x800 px`.
- Для баннеров лучше делать горизонтальные картинки `1280x360/380 px`.
- Оставляй немного пустого места вокруг товара, тогда он не будет прижиматься к краям.
