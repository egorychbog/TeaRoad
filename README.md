# TeaRoad

TeaRoad is a full-stack storefront: this repository contains the React frontend, while Supabase provides the managed backend, PostgreSQL database, and authentication. There is no separately maintained API server in this repository. Docker deployment configuration is kept in [egorychbog/deploy](https://github.com/egorychbog/deploy).
