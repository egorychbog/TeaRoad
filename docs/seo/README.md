# SEO checklist — TeaRoad

## Implemented

- Russian document language, UTF-8, responsive viewport and a descriptive base title/description are set in `index.html`.
- Route-specific title, description and canonical URL are updated for the public SPA routes: home, catalogue, gifts, promotions, about, delivery and tea picker.
- Product-detail routes use the product name and description when product data is loaded.
- Open Graph and Twitter preview metadata are populated for sharing.
- Account, authentication, favourites, cart and checkout routes receive `noindex, nofollow` meta directives and an `X-Robots-Tag` response header in Nginx/Vercel.
- `robots.txt` and `sitemap.xml` are published from `public/`. The build replaces `__SITE_URL__` with `VITE_SITE_URL`.
- The sitemap lists public static routes only. Product pages are loaded dynamically from Supabase, so they are not enumerated in this static sitemap; generating product URLs from the catalogue is a future improvement.
- Meaningful image alternative text and intrinsic width/height attributes are supplied for the main content images.
- Tailwind is built and minified with the CLI; route-level React lazy loading/code splitting is retained.
- Nginx gzip compression is enabled for text resources. Existing cache rules remain: hashed chunks are immutable, application entry files are revalidated, and images are cached for seven days.
- The app uses a system font stack; there are no separately downloaded web fonts that need `font-display: swap`.

## Crawler behaviour

Private SPA pages are marked `noindex`, but are intentionally not listed as `Disallow` in `robots.txt`. A crawler must be allowed to fetch those pages to read their `noindex` directive. This also avoids the situation where a previously indexed URL cannot be recrawled to discover the removal instruction.

The frontend calls Supabase directly on the Supabase project host. Those API responses do not pass through this project's Nginx container, so this repository cannot add `X-Robots-Tag` to the external Supabase API responses. Do not apply a global `X-Robots-Tag: noindex` to the frontend: that would de-index the storefront itself.

## Production origin

The current default canonical origin is `https://chai-path-complete.vercel.app`. Set `VITE_SITE_URL` to the final production origin when it changes. For Docker, pass it as a build argument; for Vercel, set it as a project environment variable.
